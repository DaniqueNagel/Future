## Oefening 3 – Vraag het tien mensen (week 2)

Kies tien mensen die je aan het werk hebben gezien: collega's, oud-leidinggevenden, studiegenoten, één of twee vrienden. Stuur ze dit bericht (pas aan naar je eigen toon):

> Hoi [naam], ik ben aan het uitzoeken wat ik hierna wil doen en vraag een paar mensen die me goed kennen om een eerlijk beeld. Zou je drie korte vragen willen beantwoorden? Het hoeft niet mooi geformuleerd.
> 1. Waar zou jij mij voor bellen als je ergens hulp bij nodig had?
> 2. Wat doe ik volgens jou beter dan de meeste mensen?
> 3. Welk soort werk of welke rol zie je mij over vijf jaar doen?
> Dank je wel, dit helpt me echt.

| Titel | Organisatie / sector | Welke woorden gebruiken ze voor wat ze zoeken? | Welk probleem zit erachter? | Tarief of salaris (als genoemd) | Spreekt mij aan omdat |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |

Let op twee dingen:
1. **De woorden.** De markt heeft eigen taal voor wat jij kunt. "Van alles een beetje" heet daar bijvoorbeeld "business analist", "implementatiemanager", "adoptieconsultant", "projectleider", "operations lead", "AI change manager". Verzamel die termen.
2. **Het probleem achter de vacature.** Een vacature is een organisatie met pijn. Welke pijn komt vaak terug? Dat is je markt.

## Oefening 7 – Patroonherkenning (week 4)

Kruis aan welke patronen je herkent in oefening 1 t/m 6. Twee of drie is normaal.

- [ ] **De verbinder** – vertaalt tussen afdelingen, tussen techniek en mens, tussen management en werkvloer.
- [ ] **De opruimer** – brengt orde in chaos, maakt processen, krijgt vastgelopen zaken los.
- [ ] **De snelle leerder** – pakt een nieuw domein in weken op en maakt het werkbaar voor anderen.
- [ ] **De uitlegger** – maakt ingewikkelde dingen begrijpelijk, traint, schrijft, begeleidt.
- [ ] **De aanjager** – krijgt dingen van de grond, organiseert, zet de eerste stap.
- [ ] **De afmaker** – houdt vol, levert op, zorgt dat het af is.
- [ ] **De luisteraar** – mensen vertellen jou dingen, je ziet wat er speelt, je bent de vertrouwenspersoon.
- [ ] Anders: ______________________
